# A full-stack fitness tracking application built with:

- Frontend: React + TypeScript + Vite + Clerk Auth
- Backend: Node.js + Express + TypeScript + Prisma
- Database: PostgreSQL
- Auth: Clerk Authentication & User Session Management
Deployment: Vercel Frontend + Vercel Backend

clone the repo: 
Git clone https://github.com/aarshdeepkaur2/Fitness-tracker-fullstack.git

# Install the Dependencies: 
`npm install `

# Set up Environment variable
- Must create .env file

# SEt up Databse

Genrate Prisms: 
` npm run prisma:generate `

# Start BACKEND: 
` npm run start:backend `

# Start FRONTEND 
 ` npm run start:frontend`

- Test the API running sucessfully.!!!

- Enjoy running the app !!!
